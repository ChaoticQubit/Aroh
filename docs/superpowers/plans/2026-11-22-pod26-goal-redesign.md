## What already exists (do not rebuild)

- `POST /v1/goals` (`Engine::start_goal`, `crates/aroh-server/src/engine.rs`) already takes `title`, `context`, `deadline`, `category_id`, `autonomy` and creates the `Goal` row, then starts `new-goal` (research, intake, questions, plan, approve).
- Pod 25: one question group with one Send and skip per question (`QuestionGroup.svelte`, `lib/app/questions.ts`), number questions with unit, min, max, slider and typing (`NumberInput`), run status with running step, cost and Stop, "Stopped after N min" with Retry (`/v1/runs/{id}/cancel`, `/retry`), run limit per user (`run_limits`, `/v1/settings/run-limit`, Settings field), mic through voice input, first-launch setup.
- Rows in `crates/aroh-domain/src/rows.rs`: `Category` (`color` `#rrggbb`, `seeded`), `Goal`, `GoalFile` (Storage path or link, `ingest_status`), `Preference` (`fact`, `source`, `noted_at`, `confirmed`). Tables in `supabase/migrations/20261121000000_rebuild.sql`, RLS test in `supabase/tests/rls_rebuild.sql`.
- `Engine::profile` returns confirmed preference facts as `list<string>`, read by the plan node as state `profile`.
- `teams::pick(slug, text)` picks the team by seeded category, else by keywords, else the general team.
